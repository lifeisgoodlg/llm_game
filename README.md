# 👑 간택은 제가 하겠습니다, 전하

조선 궁중 암투 텍스트 어드벤처. 인물·사건·대사를 매 판 LLM이 새로 생성합니다.

> 후궁은 중전이 될 수 없습니다. 국법이 그러합니다.
> 숙원(종4품)으로 입궁하여, 그 국법을 넘어서십시오.
> 중전의 자리에, 나아가 그 위의 자리까지.
>
> *만약 조선에 여왕이 있었다면 — 이 이야기는 그 가정에서 시작합니다.*

---

## 사용한 모델

`gpt-4o-mini` — 용도에 따라 temperature를 나눠 씁니다.

| temperature | 용도 |
|---|---|
| 0.3 | 상궁의 조언, 엔딩 에필로그 |
| 0.8 | NPC 대화 (사이드바 문안) |
| 0.9 | 주인공·인물 생성, 스토리 이벤트 |

## 스테이지

- **메인 스토리 10단계** — 스탯이 넘치면 한 단계에 두 품계까지 연속 승급
- **히든 스토리 3단계** — 중전에 오르면 열리며, 루트에 따라 내용이 갈림

## 작동 방식

1. 이름을 입력하고 `입궁하겠습니까?` 클릭
2. 주인공 설정과 궁중 인물 **7명**을 LLM이 생성
3. 매 단계 사건이 주어지고 **선택지 3개** 중 하나를 고름 (정치적 계산 / 신중한 보존 / 위험한 승부수)
4. 총애·권세·위험도·관계가 변하고, 조건을 채우면 승급
5. 중전에 오르면 히든 스토리 진입 — **영의정과의 관계**가 이후의 길을 가름

### 등장 인물 (7명)

| 인물 | 초기 관계 | 역할 |
|---|---:|---|
| 전하 | 42 | 총애의 원천. 승급 조건에 직결 |
| 대비 | 15 | **최종 상대.** 왕보다 위계가 높고 붕당을 쥐고 있음 |
| 중전 | 20 | 내명부의 직속 상관이자 곤위의 주인 |
| 경쟁후궁 | 30~45 | 같은 자리를 노리는 후궁 |
| 우호후궁 | 60 | 아군이지만 무조건은 아님. 관계에 따라 판정 보정 |
| 상궁 | 55 | 조언자 |
| 영의정 | 35 | **외조(外朝).** 히든 루트를 가르는 인물 |

### 품계

```
숙원(종4품) → 소원(정4품) → 숙용(종3품) → 소용(정3품)
→ 숙의(종2품) → 소의(정2품) → 귀인(종1품) → 빈(정1품) → 중전(무품)
```

## 엔딩

```
입궁 (숙원)
  │
  ├─ 10단계 안에 중전에 못 오름 ──────────────→ ① 사망
  │
  └─ 중전 등극  ─→  히든 진입 (여기서 안전망 해제)
         │
         ├─ 영의정 관계 50 이상 → 즉위 루트 (명분)
         ├─ 영의정 관계 50 미만 → 개국 루트 (힘)
         │
         ├─ 히든 3단계 스탯 미달 ─────────────→ ② 중전 엔딩
         ├─ 히든 중 위험도 폭발 ──────────────→ ③ 폐위·사사
         ├─ 즉위 관문 통과 ──────────────────→ ④ 여왕 등극
         └─ 개국 관문 통과 ──────────────────→ ⑤ 개국
```

| | 결말 | 조건 |
|---|---|---|
| ① | **궁에서 스러지다** | 10단계 안에 중전에 오르지 못함 |
| ② | **중전으로 남다** | 중전은 됐으나 히든 실패 |
| ③ | **사약을 받다** | 중전의 자리에서 역모 발각 |
| ④ | **옥좌에 오르다** | 반정을 일으켜 스스로 왕이 됨 |
| ⑤ | **새 왕조를 열다** | 조정을 갈아엎고 조선을 끝냄 |

**④와 ⑤는 우열이 아니라 갈림길입니다.** 여왕은 정통성을 얻지만 자신을 왕으로 만들어준 사대부에게 평생 견제당하고, 개국은 완전한 권력을 쥐지만 함께 갈 사람이 남지 않습니다.

## 시스템

### 문안 (사이드바)

인물 7명과 자유롭게 대화할 수 있지만 **한 단계에 3번**뿐입니다. 누구를 만나고 누구를 포기할지가 그 자체로 선택이 됩니다. NPC는 이전 대화를 기억하고 이어서 말합니다.

### 관계 파급 — 호감도는 제로섬입니다

한 사람과 가까워지면 다른 사람이 등을 돌립니다.

```python
RELATION_RIPPLE = {
    "왕":      {"대비": -0.5, "중전": -0.6, "경쟁후궁": -0.5},
    "영의정":   {"대비": -0.4},
    ...
}
```

전하의 총애를 받을수록 위험도가 함께 오릅니다(`KING_RISK_RATIO`). 언관이 상소를 올리고, 대비가 지켜보기 때문입니다.

### 승급 조건은 곡선에서 생성됩니다

품계별 요구치를 손으로 채우지 않고 노브에서 만들어냅니다.

```python
RANK_CURVE = {              # (첫 관문, 마지막 관문, 곡률)
    "총애":      (20, 100, 0.9),
    "권세":      (12,  88, 1.0),
    "왕호감":     (33,  58, 1.0),
    "위험도_max": (55, 100, 0.7),
}
DIFFICULTY = 0.65           # 요구 스탯 전체 배율
```

### 히든 관문 두 개

두 루트는 **서로 다른 스탯**을 요구합니다.

```python
THRONE_GATE = {"총애": 85, "권세": 78, "영의정": 60, "위험도_min":  0, "위험도_max":  70}
FOUND_GATE  = {"총애": 60, "권세": 88, "영의정":  0, "위험도_min": 60, "위험도_max": 100}
```

`위험도_min`은 개국에만 있습니다. **역성혁명은 안전하게 할 수 없습니다.**

또한 중전이 되는 순간 강등이 사라집니다. 조선의 중전에게는 강등이 없고 **폐위**가 있을 뿐이며, 그것은 곧 죽음입니다.

### 밸런스 시뮬레이터

LLM 없이 수천 판을 돌려 엔딩 분포를 확인합니다. 실제 게임 로직을 그대로 호출하므로 노브를 바꾸면 결과가 바로 반영됩니다.

```bash
python balance_sim.py
```
```bash
python balance_sim.py --tune
```

현재 밸런스 (3000판):

| 플레이 성향 | 사망 | 중전 | 폐위사사 | 여왕 | 개국 |
|---|---:|---:|---:|---:|---:|
| 안전형 | 56.4% | 43.4% | 0% | 0.2% | 0% |
| 균형형 (무작위) | 34.2% | 41.2% | 7.0% | 5.0% | 12.6% |
| **명분형** | 14.1% | 46.9% | 0% | **38.6%** | 0.4% |
| **힘형** | 23.7% | 12.7% | 24.3% | 0.1% | **39.2%** |
| 야심형 (도박) | 61.0% | 2.0% | 22.6% | 0% | 14.5% |

안전하게만 굴리면 중전에서 멈추고, 명분을 쌓으면 여왕이 되고, 힘으로 밀면 개국하고, 도박만 하면 죽습니다. 두 승리 루트의 성공률은 38.6% / 39.2%로 거의 같습니다.

## 실행

```bash
pip install -r requirements.txt
```

프로젝트 루트에 `.env` 파일을 만들고 API 키를 넣습니다.

```
OPENAI_API_KEY=your-key-here
```

```bash
streamlit run app.py
```

### 장면 이미지

배경 6장과 엔딩 일러스트 5장이 이미 `assets/` 에 들어 있습니다. 게임 중에는
이미지를 만들지 않으므로 런타임 비용과 지연이 없습니다.

다시 뽑고 싶을 때만 실행합니다. 프롬프트는 스크립트 안에 있습니다.

```bash
python scripts/generate_assets.py --force
```

## 파일 구조

| 파일 | 역할 |
|---|---|
| `app.py` | 진입점, 세션 상태, 페이즈 라우팅 |
| `game_state.py` | 품계·스탯·관계·승급/강등·엔딩 판정 |
| `game_logic.py` | 선택 처리, 히든 분기, 엔딩 확정 |
| `story_llm.py` | 주인공·스토리 이벤트·에필로그 생성 |
| `npc_generator.py` | 인물 생성, NPC 대사 |
| `parsing_json.py` | LLM JSON 파싱 + 재시도/검증 |
| `ui_game.py` | 인트로·본편·결과·엔딩 화면 |
| `ui_sidebar.py` | 인물 목록, 문안 대화 |
| `ui_theme.py` | 커스텀 CSS |
| `balance_sim.py` | 밸런스 시뮬레이터 (게임에 포함되지 않음) |
| `scripts/generate_assets.py` | 장면 배경·엔딩 일러스트 생성 (1회) |
| `rag_pipeline.py` | FAISS 검색 — **아직 게임에 연결되지 않음** |
| `palace_knowledge.py` | 참고 지식 문서 — **아직 게임에 연결되지 않음** |

## 앞으로

- **RAG 연결** — `rag_pipeline.py`와 `palace_knowledge.py`가 있으나 아직 게임에 연결되어 있지 않습니다. 조선왕조실록 국역본 등 실제 사료로 코퍼스를 교체하고 이벤트 생성에 고증을 주입할 예정입니다.
- **플레이 기록 검색** — 지난 단계의 사건과 대화를 검색해 후반 스토리가 초반을 기억하도록.
- **화면 개선** — 관계도를 방사형으로, 엔딩마다 전용 카드로. 둘 다 SVG 를 동적으로
  그려야 해서 Streamlit 에서는 지저분해집니다.
